# Security Policy

## Reporting a vulnerability

Please do not open public issues for security problems.

Use GitHub's private vulnerability reporting instead:
[Report a vulnerability](https://github.com/alvnukov/cozyphi/security/advisories/new).

Include what you found, how to reproduce it, and any impact you see. Reports
are acknowledged within a few days; coordinated disclosure is preferred, and
credit is given unless you ask to stay anonymous.

## Scope

The cozyphi agent binary, its tools and permission gates, and the workflows
in this repository. Vulnerabilities in dependencies are reported upstream and
tracked here once they affect cozyphi.

## Supported versions

Only the latest release line receives security fixes.
