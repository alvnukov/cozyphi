## Body

**Проблема.** Контекст сессии можно только урезать вперёд (`/context` → trim/delete) или сжать (`/compact`). Нельзя вернуться к состоянию на момент сообщения N, ответвить сессию от N или задать побочный вопрос, не засоряя контекст модели.

**Что делаем.** Три операции, управляемые мышью в ленте транскрипта: **откат** контекста к сообщению, **форк** сессии с сообщения, **/btw** — побочный вопрос по текущему контексту или по контексту на момент любого сообщения; ответ виден, в модель не попадает.

**Опоры в коде.** Лог сессии уже дерево с курсором: `SessionBaseEntry{ID, ParentID}`, `Manager.leafID`, `walkPath`/`buildSessionContext` (internal/session/manager.go), `GetBranch(fromID)` режет ветку от любой записи и никем не используется. Одноразовый запрос без записи в историю — паттерн `client.Stream(msgs)`/`client.Compact` (internal/llm/client), так работает session/compaction. Мышиный конвейер единый: `PointerShape` → `App.updateHover` → `DrawContext.Hover` → `Hovering`/`ApplyHoverRect`/`HoverRegioner`, dwell-тултипы через `HoverTooltiper`, блок получает клик первым через `MessageList.Handle`. Место под кнопки без изменения формы строки: пустая строка отступа `UserBlock`, заголовок `▣ …` `AssistantBlock`. Форк открывается через `sessions.Registry`/`View` (мультисессия).

**Решения.**
- Откат — сдвиг курсора `leafID` в том же файле новой записью; старая ветка остаётся в логе; есть «отменить откат»; без подтверждения, потому что обратимо.
- Форк — новая вкладка: копия ветки до якоря в новый файл сессии; исходная не трогается.
- /btw — строка-aside в транскрипте, сохраняется как non-context запись (по образцу `session_title`), в `BuildContext` не попадает никогда; свой цвет темы, сворачивается; на композере — кнопка-lead, хоткей, подсказка.
- Выбор сообщения — кнопки в самом сообщении, всегда видны (приглушённые, в строке отступа промпта / заголовке ответа), под курсором подсвечиваются, при задержке — тултип, клик действует. Слэш-команды `/rewind`, `/fork`, `/btw` — паритет для клавиатуры и тестов. `/context` — отложенный паритет.

**Семантика якоря** (одна для всех). Якорь — запись сообщения; ветка = `GetBranch(anchor)` включительно. Откат и форк допускают якорем только границу хода: пользовательский промпт («до этого промпта», текст промпта возвращается в композер) или последнее assistant-сообщение хода без незакрытых tool-вызовов («после этого ответа»). /btw допускает любую запись сообщения. Все три отказываются, пока идёт ход (как `/compact`); кнопки тогда приглушены сильнее, тултип объясняет.

**Полоса кнопок.** Справа в строке отступа/заголовке: `↶ откат  ⑂ форк  ? btw`; цвет `Muted`; hover-регион на каждую кнопку, тинт `ApplyHoverRect`, рука `ShapePointer` только над кнопками, остальное — `ShapeText`; действия — колбэки `OnRewind/OnFork/OnAside`, которые вставляет `Mapper` (виджеты dumb). На assistant-сообщении полная полоса только у последнего текстового ряда хода; на промежуточных — только `? btw`.

**Дети и порядок.** live-transcript-entry-ids → transcript-message-actions → session-leaf-rewind → session-fork-to-tab; live-transcript-entry-ids → aside-entry-and-engine-ask → aside-transcript-row; (transcript-message-actions, aside-entry-and-engine-ask) → aside-composer-mode; (rewind, fork, aside-core) → context-pane-message-actions; всё → docs-context-window-management.

**Отложено.** Переключение между ветками дерева в UI (после отката старая ветка только в логе); выбор модели для aside; меню по правому клику.

**Закрытие.** Эпик закрывается, когда все дети done и документация обновлена. Код в эпике не меняется — только в детях, каждая в своём ворктри `.worktrees/<id>`, доставка PR-ом, гейты только по изменённым пакетам.

## Acceptance Criteria

- В ленте у каждого промпта и у последнего ответа хода видны кнопки откат/форк/btw; клик работает, hover подсвечивает, dwell показывает подсказку
- Откат возвращает контекст до выбранного промпта или после выбранного ответа, обратим командой /rewind back, старая ветка остаётся в файле сессии
- Форк открывает новую вкладку с копией ветки до якоря; исходная сессия не изменяется
- /btw отвечает по текущему контексту или по контексту на момент выбранного сообщения; ответ показан отдельным цветом, сворачивается, сохраняется в файл и никогда не входит в BuildContext
- Композер имеет режим btw с кнопкой-lead, хоткеем и подсказкой; /rewind, /fork, /btw работают с клавиатуры
- Документация (doc/session.md, doc/tui.md, AGENTS.md, help) описывает дерево сессии, откат, форк и aside; все дети done
