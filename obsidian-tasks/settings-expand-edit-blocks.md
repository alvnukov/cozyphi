## Body

**Проблема.** Разворачивание дифф-карточек (edit/write) сейчас захардкожено: во время хода открываются сами, по концу хода складываются. Пользователь хочет управлять этим галочкой в settings-сайдбаре.

**Что сделать.** Галочка в settings: включена — блоки редактирования кода отрисовываются развёрнутыми; выключена — отрисовываются свёрнутыми. При СНЯТИИ галочки все развёрнутые дифф-блоки в ленте сразу сворачиваются. При УСТАНОВКЕ в ленте ничего не меняется — влияет только на будущие блоки. Явный тумблер пользователя на конкретной строке по-прежнему главнее.

**Критерий.** Галочка видна и переключается в settings; новые дифф-блоки рождаются развёрнутыми/свёрнутыми по её состоянию; снятие мгновенно сворачивает развёрнутые дифф-блоки в ленте; установка ленту не трогает; настройка переживает рестарт (если settings персистятся); тесты на оба перехода.

**Результат.** Сделано: коммит db20326 (feat(tui): sidebar switch for edit cards' default expansion), merge в main 66a14b2. В settings-вкладке сайдбара появился переключатель `[x] expand edits` (по умолчанию включён), персистится в UIState как инверсный флаг expandEditsDisabled — без миграции. Снятие галочки мгновенно сворачивает все развёрнутые дифф-карточки в ленте и пиннит их свёрнутыми; установка ленту не трогает — действует только на будущие карточки (заморозка текущего состояния видимых строк). Явный тумблер на конкретной строке главнее галочки в обе стороны. Старый механизм turnTools (авто-открытие на время хода) удалён целиком. Гейт make fmt-check lint test rc=0, make test на main rc=0; тесты на оба перехода, персистентность и клик по строке в сайдбаре добавлены. CHANGELOG и internal/tui/DESIGN.md обновлены.
