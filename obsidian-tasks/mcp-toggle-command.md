## Body

**Что:** слэш-команда **/mcp** открывает диалог управления MCP-серверами: список серверов из конфига, переключение вкл/выкл.

**Почему:** нужен ручной контроль того, какие серверы видит модель (шум в контексте, отладка, безопасность), с сохранением выбора между сессиями.

**Как:** персистентный флаг включённости per-server; менеджер MCP не подключает выключенные при старте и отключает на лету; диалог — компонент в internal/components, проводка в internal/tui. Инвариант: серверы достигают модель только как mcp_list/mcp_inspect/mcp_call.

**Done (2026-09-05).** Реализована команда /mcp: диалог со списком MCP-серверов и их состоянием (connected/off/failed/configured), переключение вкл/выкл по Enter с обновлением страницы; выключенный сервер сразу исчезает из mcp_list/mcp_inspect/mcp_call и промпта (Pool.SetEnabled + Engine.RefreshTools), выбор персистится в mcp.json (disabled[]). Сайдбар помечает выключенный сервер «–», `cozyphi mcp list` — пометкой disabled, doctor пишет «disabled (enable with /mcp)». Ветки: feature/mcp-toggle-command (629c4e9), merge --no-ff в main (9aa56f8). Гейты: golangci-lint 0 issues, тесты изменённых пакетов зелёные.
