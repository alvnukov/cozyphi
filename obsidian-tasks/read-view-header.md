## Body

**Проблема:** view-режим `read` отдаёт голые нумерованные строки — модель не знает ни размера файла, ни общего числа строк, ни какой диапазон показан, и вынуждена делать разведывательное чтение перед пагинацией.

**Решение:** открывать страницу строкой `@read <path> (<stats>, showing N-M)`. Для файла, загруженного целиком, stats — число реальных строк и размер; для потокового окна (файл больше readMaxHashBytes) общее число строк неизвестно, поэтому только размер. Страница за EOF печатает заголовок без диапазона. Edit-режим остаётся с `@file <path>#TAG` и заголовка `@read` не получает.

**Границы:** только `internal/tools/readtool`; hashline-контракт edit-режима не трогается.

## Acceptance Criteria

- view-заголовок несёт число строк (когда известно), размер и показанный диапазон
- хвостовой пустой элемент от финального перевода строки не считается строкой
- потоковое окно для большого файла отдаёт заголовок без счётчика строк
- edit-режим не содержит @read
- make fmt-check lint test зелёные
