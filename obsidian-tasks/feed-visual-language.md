## Body

**Проблема.** У ленты нет единого визуального скелета: блоки различаются только отступами и глифами, цвет используется несистемно, код и диффы не отделены подложкой. Ритм ленты не читается — глазу не за что зацепиться при беглом скролле.

**Что сделать.** (1) Вертикальная черта-гуттер слева у каждого блока, окрашенная по роли (user / assistant / tool / error) — opencode-стиль, скелет без рамок. (2) Единая шкала отступов для всех блоков (сейчас messageIndent + ад-хок сдвиги). (3) Дисциплина цвета: цвет только для статуса (зелёный/красный/жёлтый), всё остальное — два тона foreground; убрать несистемные акценты. (4) Спокойные фоновые подложки у кода и diff-карточек. Никаких рамок-коробок вокруг блоков. Ложится поверх блоков из [[feed-semantic-tool-rows]].

**Критерий.** Каждый блок ленты несёт роль-гуттер; отступы всех блоков на одной шкале; цвет вне статусных глифов/строк не используется; код и диффы визуально отделены подложкой; скриншот до/после в CHANGELOG-записи.

**Результат.** Сделано (commit 24df148, merge в main 18d333d). (1) Роль-гуттер: у каждого ассистентского блока тонкая черта ▏ в колонке 0 (`gutterBar` в inset.go), и это единственный роль/статус-сигнал строки: приглушённая dim-черта у рабочих строк (`quietGutter` — thinking, tool, bash, agent, diff, turn-summary), muted без dim у текста ассистента (рисуется внутри кэшируемой поверхности `updateSurface`, от префикса перерисовки — тема входит в ключ кэша), Destructive при error/rejected (tool/diff/agent/bash). User-блок сохраняет тяжёлую ┃-панель, compaction — полноширинный разделитель без гуттера. Глиф ▏ — это хром: добавлен в `IsTranscriptChrome`, выделение-копирование его отфильтровывает; намеренно не «│» дерева и таблиц — тот остаётся контентом. (2) Единая шкала: `messageIndent` 1→3 — гуттер в 0, контент с 3-й колонки, тела разворачиваемых блоков на 5-й; ад-хок сдвиги не понадобились, все блоки уже считали от messageIndent. (3) Дисциплина цвета: статичные имена тулов в tool/diff/agent (и детей agent-дерева) сняли акцент `ToolName` → обычный Foreground; акцент теперь означает только «выполняется» (спиннер, streaming-«thinking» с волной, $ работающей команды). (4) Спокойные подложки: новый `components.FillRowsBg` (по образцу ApplyBlockHighlight: Bg-проход по ячейкам, пустые → пробел, Trail сохраняется) кладёт BackgroundPanel под ханки диффа, развёрнутый вывод bash и развёрнутый вывод тула, от колонки 2 до правого края; строки ошибок подложку не получают — красный текст остаётся самым громким на строке. Рамок-коробок нет. Тесты: TestAssistantFamilyInset переписан под новый контракт (▏ в 0, контент в 3, +turn-summary), новые TestGutterTurnsDestructiveOnFailure и TestExpandedBodiesGetABackdrop (подложка у ханков/вывода, титульная строка и строка ошибки — без неё). Скриншот до/после — текстовый скетч в CHANGELOG-записи (TUI, до/после в виде кода). DESIGN.md «The transcript feed» дополнен абзацем о визуальном языке. Гейт rc=0, happ-диагностика чистая по всем тронутым файлам, main `make test` rc=0.
