## Body

**Контекст.** Память cozyphi живёт в per-repo корпусе `~/.claude/projects/<encoded-git-root>/memory/`. Пользователь просит уметь помечать отдельную память глобальной для всех реп — доступной из любой репы.

**Задача (после grilling 2026-09-16).** Глобальность — это ключ `scope: global` во фронтматтере (плоско или под `metadata:`, как `type` и `pin`). Файл никуда не переносится: харнесс держит его копию в каждом известном корпусе (`~/.claude/projects/*/memory`) плюс канонический `~/.cozyphi/memory`. Сессия читает ровно один корпус — глобальный факт это обычный файл, который лежит везде. Синхронизатор сравнивает mtime: самая свежая копия имени побеждает и переписывает старые в любую сторону, так что правка из любой репы и из Claude Code доезжает до остальных. Копия штампуется временем источника, поэтому устоявшееся дерево ничего не пишет. Синхронизатор никогда не удаляет и не перезаписывает одноимённую локальную память; конфликт называется в промпте. Спека: `specs/global-memory.md`.

**Границы.** memory tool не пишет сам факт — только его учёт (забыть, сделать глобальным, вернуть локальным); ни одно действие не принимает путь, репозиторий или чужой корпус — раздачей занимается харнесс, чтобы модель не лезла куда не следует. Субагентам магазина памяти по-прежнему нет. Гейт памяти не трогаем: `ActionMemory` не мутирующее действие, `policy.MemoryDir` — исключение из workspace-only, а не чекпоинт. Работа в ворктри `.worktrees/global-memory`; гейты только по изменённым пакетам; один подписанный коммит; PR — только с разрешения.

## Acceptance Criteria

- `scope: global` (плоско или под `metadata:`) делает факт глобальным; харнесс держит копию файла в каждом корпусе `~/.claude/projects/*/memory` и в каноне `~/.cozyphi/memory`; сессия читает ровно один корпус
- Синхронизация по mtime в любую сторону: правка из любой репы и из Claude Code доезжает до остальных; проход по устоявшемуся дереву ничего не пишет
- Синхронизатор ничего не удаляет и не перезаписывает одноимённую локальную память; конфликт называется в промпте
- `global`/`local` в memory-инструменте и в CLI, `*` в списках; `local` и `forget` архивируют копии во всех корпусах
- Модель не достаёт до чужих корпусов: ни одно действие инструмента не принимает путь или репозиторий
- Тесты `internal/memory` и `internal/tools/memorytool` зелёные
- doc/memory.md, CHANGELOG.md ## [Unreleased] и AGENTS.md обновлены
