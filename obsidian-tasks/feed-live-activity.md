## Body

**Проблема.** Активность размазана по ленте: спиннеры на каждой tool-строке, но нет одного места, отвечающего на «что модель делает прямо сейчас, как давно и сколько это стоит». При автономной работе теряется ощущение контроля.

**Что сделать.** Единая строка активности у нижнего края ленты во время стрима: текущий тул/фаза (глагол), elapsed текущего хода, поток токенов, hint прерывания (Esc). Анимация в духе Claude Code — по явному пожеланию пользователя, с уточнением «буковки переливаются аккуратненько, мягко»: главный эффект — шиммер по буквам глагола-статуса, мягкая волна яркости, бегущая по тексту (посимвольный градиент dim→foreground→dim, смещающийся на кадр), а не мигающий глиф; плавно (кадр ~80–120мс), без смены цвета, только яркость. Гаснет при завершении хода — итог уезжает в meta-строку ассистента и (после [[feed-turn-grouping]]) в резюме хода. Не дублировать спиннеры: per-row спиннер остаётся только у активной строки.

**Критерий.** Во время стрима видна одна анимированная строка (глиф-пульс + глагол) с текущим действием, elapsed и токенами; она исчезает по завершении; hint прерывания присутствует; двух одновременных спиннеров в видимой области нет.

**Результат.** Сделано (commit 94ff26b, merge в main df6cc64). Футер во время стрима становится единой строкой активности `✻ <model> · Generating… · 42s · ↓1.2k` c право-прижатым «Esc interrupts» (ожидающий update-hint приоритетнее). (1) Анимация по пожеланию: волна яркости по буквам глагола — `components.WaveLabel` (перенос waveLabelRunes из thinking-блока в общий `internal/components/shimmer.go`, thinking делегирует туда же): посимвольный blend dim→accent по косинусу, фаза от wall-clock (кадр 80мс, fps-независимо), только яркость, без смены цвета и мигания; не-truecolor фолбэк — жёсткий акцент на голове волны. Глиф-пульс — `components.PulseStyle`: ✻ «дышит» между Muted и акцентом по медленному косинусу (период 1.2с); перерисовку уже тикает существующий `ctx.WakeIn(spinnerInterval)`. (2) Elapsed и токены текущего хода — `liveTurn(snap)`: старт первого таймированного ассистентского раунда после последнего отправленного user-сообщения и сумма CompletionTokens раундов хода (счётчик оживает по мере закрытия раундов агентного хода). (3) Спиннеры не дублируются: Knight-Rider scan-бар убран из футера (Scan/PaintScan в status остались как API), единственный спиннер-глиф в видимой области — на активной строке ленты (общий footer.Spinner() → mapper). (4) Строка гаснет по RunEndedMsg → idle-путь футера без изменений (hookStatus/jobs/session-id сохранены в обоих путях, обрезка span-ов новым clipSpans с «…» до зазора hint'а). Тесты: shimmer_test.go (волна сохраняет текст, blend только яркости, фолбэк без truecolor, пульс в границах), footer_live_test.go (фаза+elapsed+токены+hint, отсутствие scan-бара, гашение по концу хода, клип при узком футере, clipSpans). DESIGN.md и CHANGELOG дополнены. Гейт rc=0, happ-диагностика чистая, main `make test` rc=0.
