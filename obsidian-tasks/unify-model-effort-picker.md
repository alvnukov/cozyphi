## Body

Унифицировать отображение и выбор моделей в TUI. Информационные строки с моделью должны включать effort. Все входы выбора модели должны вести в общий пикер, который после модели условно открывает выбор поддерживаемого effort.

**Started (2026-09-04).** Дизайн подтверждён пользователем: effort во всех надписях (композер/футер уже есть; добавить thinking-заголовок, сводку-тост, поля плана), общий двухшаговый пикер во всех пяти местах выбора модели, /model без аргумента открывает пикер, /effort убирается.

## Acceptance Criteria

- Все пользовательские информационные надписи, показывающие выбранную модель, также показывают её effort, когда effort задан или поддерживается.
- Все места выбора модели используют один общий пикер вместо расходящихся реализаций.
- После выбора модели пикер предлагает выбрать effort только для моделей, у которых доступны уровни effort; для остальных выбор завершается сразу.
- Текущее поведение выбора модели без effort не регрессирует; добавлены тесты релевантных сценариев.
- Пользовательское изменение отражено в CHANGELOG.md под Unreleased.

## Verification Plan

1. Найти все места отображения и выбора модели и зафиксировать общий контракт.
2. Добавить/обновить unit-тесты общего пикера для моделей с effort и без него.
3. Запустить форматирование, сборку и тесты только для изменённых пакетов.
4. Один раз запустить scoped golangci-lint перед финальным коммитом.
